Today we're releasing an updated checkpoint of our decision model `hs-decide-1-flash`. It takes a mix of text and images and handles requests up to 131,072 tokens, up from the 65,536 the first checkpoint was trained on. It scores higher overall on our evals and raises its Decision Index score. It's available now as open weights on Hugging Face and on Hindsight Inference.

## Images

Images are now a native part of the model. The same model makes decisions about images and ranks them. It can judge a photo, a screenshot or a PDF page, and rank pages and pictures against a query along with text.

Requests use the same System One API as TypeSafe's Jev 1.14, with images sent as named assets. An app written for that API works with `hs-decide-1-flash` by changing the model name.

We added a vision encoder and post-trained the model on rerank requests from real [knowledge banks](/blog/2026/11/24/knowledge-banks), along with PDF page images and photo search results, so it ranks images and text together.

## Longer context

The new checkpoint handles requests up to 131,072 tokens. With memories of around 400 tokens, the first checkpoint could rank about 160 memories in one request before Hindsight had to split it. The new checkpoint ranks about 320.

## Better performance in Hindsight

With the new checkpoint, Hindsight passes 90.9% of our system eval cases, up from 80.9% with the first one.

| Operation (cases) | First checkpoint | New checkpoint |
|---|---:|---:|
| Recall (23) | 68.1% | 88.4% |
| Reflect (15) | 95.5% | 100.0% |
| Mental model refresh (16) | 79.2% | 89.6% |
| Consolidation (14) | 88.1% | 86.9% |
| **All operations (68)** | **80.9%** | **90.9%** |

To see how well the model works on public data, we ran these datasets in the request format Hindsight sends:

- LoCoMo and LongMemEval simulate recall across a long memory history.
- Wikipedia revisions simulate knowledge pages whose information keeps changing.
- Dialogue NLI simulates the new facts that consolidation checks against stored ones.
- SQuAD 2.0 and HotpotQA simulate the questions that reflect answers from evidence.

## Better general decisions

The [Decision Index](https://benchmarks.hindsight.vectorize.io/models/decision) measures how well a model makes decisions outside of Hindsight across 37 public benchmarks. The new checkpoint scores 42.6, 6.5 points better than the first one's 36.1.

## How to use it

### Send images

Images can go in the state, the questions or the answer options. Put each image in `assets` and refer to it by name:

```json
{
  "state": {
    "photo": "img-1",
    "note": "The customer says the screen arrived cracked."
  },
  "questions": {
    "damaged": {
      "type": "noul",
      "instructions": "Does img-1 show a damaged screen?"
    }
  },
  "assets": {
    "img-1": {
      "type": "image",
      "format": "png",
      "data_base64": "<base64 PNG>"
    }
  }
}
```

### Hindsight Inference

The new checkpoint is live on [Hindsight Inference](https://inference.hindsight.vectorize.io), so you can call it at `POST /v1/systemone` with an API key and no GPU. To use it from Hindsight, set `HINDSIGHT_API_DECISION_MODEL_PROVIDER=hindsight` and put your Hindsight Inference key in `HINDSIGHT_API_DECISION_MODEL_API_KEY`. [Decision Models](/developer/decision-models) has every setting.

### Run it yourself

The weights are on [Hugging Face](https://huggingface.co/hindsight-ai/hs-decide-1-flash), and a plain download gets the new checkpoint. To pin it, add `--revision 1127` to `hf download`. The first checkpoint stays at `--revision 1103`.

On a GPU with vLLM:

```bash
hf download hindsight-ai/hs-decide-1-flash --local-dir hs-decide-1-flash
pip install vllm==0.32.0 ./hs-decide-1-flash/serving
hindsight-decision-serve hs-decide-1-flash \
  --port 8000 --api-key your-key
```

The same package also runs the model with MLX on an Apple silicon Mac (`hindsight-decision-serve-mlx`), or with Transformers on a CPU (`hindsight-decision-serve-transformers`). The [model card](https://huggingface.co/hindsight-ai/hs-decide-1-flash) has the install steps for each.

Then point Hindsight at your server:

```bash
export HINDSIGHT_API_DECISION_MODEL_PROVIDER=hindsight
export HINDSIGHT_API_DECISION_MODEL_BASE_URL=http://localhost:8000
export HINDSIGHT_API_DECISION_MODEL_API_KEY=your-key
```
