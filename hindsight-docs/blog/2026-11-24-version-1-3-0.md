Hindsight 1.3.0 ships **knowledge banks**, on by default. Alongside them, a bank can now tell MCP clients how to use it, a big document no longer holds up every other bank's LLM calls, consolidation and reflect read memory times in the bank's own time zone, and recall's recency weight is a setting. Most of the rest is reliability work across retain, reflect, mental-model refresh and bank export. **Everyone on 1.2.x should upgrade** — see the [changelog](/changelog) for the full list.

## Knowledge banks

Knowledge banks keep your documents (PDFs, Office files, spreadsheets, images, audio and video) exactly as written, search them with multimodal retrieval, and need no LLM to fill. Link one to a memory bank and reflect answers from both. Read the full story, benchmarks and costs in [Introducing Knowledge Banks](/blog/2026/11/24/knowledge-banks).

In 1.3.0 they are **on by default**, and you can reach them from everywhere: the control plane, the `hindsight kb` CLI commands, the Python and TypeScript clients, and MCP (all knowledge banks, or one at `/mcp/kb/{bank_id}/`). Search can skip the reranker per request (`enable_reranking: false`) or server-wide (`HINDSIGHT_API_KB_ENABLE_RERANKING`). See [Knowledge Banks](/developer/knowledge-banks) to get started.

## MCP instructions per bank

A bank can now carry its own MCP server instructions: which page to read first, which tags to save facts with, and so on. Set `mcp_server_instructions` in the bank config (or `HINDSIGHT_API_MCP_SERVER_INSTRUCTIONS` server-wide, up to 4,000 characters). Every client that connects to the bank's `/mcp/{bank_id}/` endpoint receives it, so you stop pasting the same prompt into each agent. A change applies to the next connection.

## Fair LLM sharing

LLM calls used to wait in arrival order, so one big retain could put hundreds of calls ahead of everything else on the worker. Now a free slot goes to each tenant in turn, then each bank in turn, then the document closest to done. A small retain behind a big one finishes almost at once, and a document alone still gets every slot. No settings to change.

## Times in the bank's time zone

Stored times used to reach the model as UTC without saying so, so a fact from the morning of 8 November in Shanghai could become "7 November" in an observation. Consolidation, reflect and the observation tree now show memory times in the bank's `default_timezone` and name the zone. UTC banks look the same. In banks with a time zone set, an observation near a month boundary can move to a different month file in the tree and in `hindsight fs mount`.

## Recall recency weight

`HINDSIGHT_API_RECENCY_ALPHA` (0 to 1, default `0.2`) sets how much recency can move a recall score: at most half of alpha, up or down. Unset, ranking is unchanged. It sits next to the existing `HINDSIGHT_API_RECENCY_DECAY_*` settings.

## Memory defense: skip patterns

A `sensitive_data` rule can now leave out individual patterns, for example keep redacting everything but credit card numbers:

```json
{ "on": "sensitive_data", "action": "redact", "exclude": ["credit_card"] }
```

An unknown pattern name is rejected, so a typo can't silently leave a pattern on. Set it through the bank config API; the control plane keeps it when you save other settings.

## Antigravity provider

Set `HINDSIGHT_API_LLM_PROVIDER=antigravity` to drive Google's `agy` CLI, so a Google AI subscription with Antigravity can serve retain, consolidation and reflect. Hindsight only launches the binary, runs it with every tool turned off, and never touches its credentials. See [Models](/developer/models) for setup.

## Reliability fixes

- **Retain:** a replace retried after a newer one no longer rolls the document back; a re-extracted document keeps each fact's first-retained date; a large append to a JSON conversation no longer re-extracts the whole document; numeric entity names no longer fail a chunk.
- **Reflect:** `HINDSIGHT_API_LLM_STRICT_SCHEMA_REFLECT=false` now also reaches the tool turns, which helps models that run away under a strict grammar. A reply cut off at the output limit is sampled once more.
- **Mental models:** a failed refresh keeps the existing structured output, a rate-limited refresh step no longer pauses the model, and a page whose cited facts are all gone is rebuilt instead of kept.
- **LLM providers:** a content-filter block counts as a content-policy refusal on every provider, Mistral's typed replies are read as text, malformed JSON is repaired more often, and a 422 context-limit reply is handled as a window overflow.
- **Export:** history and attachment entries can pass 4 GB, and exporting a bank that doesn't exist fails clearly.
- **Oracle:** faster memory operations through a new index, batched link inserts and shared cursors.
- **API:** updating a document's tags no longer deadlocks, a first directive creates its bank instead of failing with a 500, and a list limit above the cap is trimmed to it.
- **MCP:** an allowlist that names no built-in tool now registers none.
- **Ops:** the OpenAI embeddings startup check retries on 429, and the slim Docker image no longer overwrites the full image's `:latest` tag.
