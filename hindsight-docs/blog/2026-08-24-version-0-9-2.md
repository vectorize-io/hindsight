Hindsight 0.9.2 is the largest reliability release since [0.9.0](/blog/2026/08/07/version-0-9-0). It hands you the controls on things that used to be guessed for you — **the time window a recall searches**, **how often mental models refresh**, **which banks get their own vector index** — adds **Knowledge Base editing over MCP** and a **GitHub Copilot** provider, and lands a long list of correctness fixes. **Everyone should upgrade**: several fixes protect data you've already stored.

<!-- truncate -->

- [**Recall You Can Steer**](#recall-you-can-steer): Pass the time window directly instead of phrasing it in English, and get sharper results on long queries.
- [**Knowledge Pages, Editable Over MCP**](#knowledge-pages-editable-over-mcp): Full Knowledge Base CRUD as native MCP tools, visible refresh triggers, and refreshes that pace themselves.
- [**More Model Control**](#more-model-control): A GitHub Copilot subscription provider, asymmetric embedding prefixes, and provider fixes across Ollama, Voyage, Azure and Vertex.
- [**Built for Many Banks**](#built-for-many-banks): Vector indexes earned by size, sweeps proportional to your tenant count, and a paginated bank list.
- [**Correctness You Don't Have to Watch For**](#correctness-you-dont-have-to-watch-for): Failures that surface instead of writing something wrong, and a deep pass over retain, consolidation and redaction.

## Recall You Can Steer

Recall used to work out the time range you meant by parsing dates out of your query text. If you already knew the range — a date picker in your UI, an agent that had resolved "last quarter" itself — you had to phrase it in English and hope the parser agreed.

- **Pass the window directly.** Recall now accepts a `temporal_window` with a `start` and `end`. When you set it, it's used verbatim and the natural-language extraction is skipped entirely — which is also the point: that parsing is pure CPU work that costs up to ~1.3s on document-sized query text, exactly the shape of query that consolidation and reflect issue internally.
- **Long queries stay selective.** When you search with a paragraph rather than a phrase, keyword search now keeps the most selective terms instead of drowning the signal in common ones.
- **The budget is respected end to end.** A recall's result budget now reaches the vector index itself, and a fact that doesn't fit the budget is skipped rather than cutting the whole result short — so a single oversized fact can no longer empty a response that had good matches behind it.
- **`2024` is not always a year.** A lone four-digit number in a query is no longer assumed to be a year, so searching for a part number or an error code stops silently narrowing your results to a decade.

## Knowledge Pages, Editable Over MCP

- **Full Knowledge Base CRUD over MCP.** Creating, reading, updating and deleting Knowledge Pages are now native MCP tools, so an agent can maintain its own wiki without going through the REST API.
- **Refresh triggers are visible.** Each page's refresh trigger now appears in the tree view, so you can see at a glance what causes a page to rebuild instead of opening it to find out.
- **Refreshes pace themselves.** Automatic mental-model refreshes now respect a minimum interval, set with `HINDSIGHT_API_MENTAL_MODEL_MIN_REFRESH_INTERVAL_SECONDS`. A busy bank used to be able to trigger thousands of refreshes a day, each one an LLM call, for content that had barely moved.
- **You can see what a refresh did.** A refresh now records its outcome on the operation itself, so "did anything actually change?" is a question you can answer without diffing the page.
- **Retracted facts get unsaid.** When a page cites facts that no longer exist, the mental model now retracts them properly instead of continuing to assert something the memory no longer supports.
- **Staleness is answered per scope**, not from a single bank-wide watermark, so a page tagged to one project doesn't read as stale because an unrelated part of the bank moved. The control plane shows this per model, with the same wording everywhere.

## More Model Control

- **A GitHub Copilot provider.** Set `HINDSIGHT_API_LLM_PROVIDER=github-copilot` to run Hindsight's LLM lanes on a Copilot subscription — no API key required.
- **Asymmetric embedding prefixes.** Many modern embedding models expect a different instruction prefix for a query than for a stored passage. You can now set `HINDSIGHT_API_EMBEDDINGS_QUERY_PREFIX` and `HINDSIGHT_API_EMBEDDINGS_PASSAGE_PREFIX` independently for text-in providers, and Voyage's built-in asymmetric behaviour is preserved rather than flattened.
- **Ollama honours your context length.** Free-form Ollama calls now go to the API that actually applies `num_ctx`, so the context window you configured is the one you get.
- **Consolidation uses your temperature.** The configured temperature is now forwarded to consolidation calls instead of being dropped.
- **Fewer provider surprises.** Automatic cache affinity is off for Azure OpenAI, where it caused routing errors; Vertex AI's EU and US regional endpoints work again; batch retain runs through a batch-capable model member; and a missing llama.cpp is now reported plainly instead of looping on connection errors.

## Built for Many Banks

If you run Hindsight with thousands of banks, this release changes what that costs.

- **Vector indexes are earned, not assumed.** Every per-bank vector index lives on the shared memories table and is planned against by every _other_ bank's queries — so creating three per bank puts a hard ceiling on how many banks you can have. Set `HINDSIGHT_API_VECTOR_INDEX_MIN_ROWS` (try `10000`) and a bank only gets an index once it's big enough to need one; smaller banks use exact search, which is both faster and exact. The default stays `0`, meaning off, so existing deployments behave exactly as before.
- **Sweeps sized to your deployment.** Cross-tenant maintenance sweeps now scale with the number of tenants instead of doing constant per-tenant work, the retention sweep runs in batches instead of one long transaction that stalls foreground queries, and maintenance skips a schema that's under concurrent schema change rather than deadlocking against it.
- **A lighter worker loop.** Background workers now use one pooled database connection per poll cycle with a single statement of session setup, cutting steady-state overhead on an idle deployment.
- **A paginated bank list**, so listing banks stays workable as their number grows.
- **Traced background work.** Worker runs are now traced and join the caller's trace, so an async retain is visible end to end rather than disappearing after the API returns.
- **Bank config is saved atomically.** Configuration is validated and persisted as one unit, so a rejected value can't leave a bank half-updated.

## Correctness You Don't Have to Watch For

The theme of this release is failing loudly rather than writing something wrong:

- **Reflect no longer stores a placeholder.** A run that produces no answer now fails instead of saving "I don't know" into memory, where it could overwrite a mental model that had real content in it.
- **Fact extraction notices schema drift.** If the stored schema has moved underneath it, extraction retries and then surfaces a clear failure instead of quietly extracting nothing.
- **Misconfiguration fails.** A malformed memory-defense policy now fails the retain instead of skipping screening entirely, and wrong retain options raise instead of falling back to a silent default.
- **Content-policy refusals stop being retried.** A provider refusal is a permanent outcome, not a transient error, and is now treated as one.

And a broad pass over stored data:

- **Re-retaining content deletes the chunks it removed**, so an edit that only cuts text no longer leaves the removed passages behind and recallable.
- **Merging observations preserves their original dates** instead of collapsing them.
- **Memory timestamps are stamped on every write that changes a memory**, so recency ranking reflects reality.
- **Entities aren't merged on history alone** — a name that once resolved to an entity no longer forces every future match onto it.
- **Secret redaction uses ASCII token boundaries**, so a key sitting next to CJK text is masked like any other.
- **Null metadata values are dropped** at retain and recall rather than flowing downstream, **batch recovery is scoped to the account that submitted the batch**, and **embedding config inherits your unset LLM settings** instead of overwriting them.

Plus the smaller things: knowledge-tree writes are serialized so concurrent edits can't corrupt the tree, page scope survives a trigger update, at most one refresh is queued per mental model, list endpoints report real totals for pagination, the CLI exits non-zero on an invalid API URL and drops ANSI color when it isn't attached to a terminal, and the control plane keeps your memories search open when you clear the query. See the [changelog](/changelog) for the full list.
