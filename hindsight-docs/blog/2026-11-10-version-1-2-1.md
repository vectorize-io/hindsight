Hindsight 1.2.1 lets you switch embedding models while servers keep running, use different embedders for queries and stored text, plug in your own LLM class, and fall back to the reranker when the decision model fails a recall. The rest is reliability and speed work across retain, consolidation, recall, transfer and the worker. **Everyone on 1.2.0 should upgrade** — see the [changelog](/changelog) for the full list.

## Re-embed without downtime

A server won't start on an embedding model with a different dimension once memories are stored. Now you can switch in place: set the new `HINDSIGHT_API_EMBEDDINGS_*` variables where you run the command, then run `hindsight-admin reembed --all-schemas` (or `--schema <name>`). Servers keep serving reads and writes while it re-embeds; once every server runs the new model, `--finish` lifts the last write guard. See [the admin CLI](/developer/admin-cli) for the full procedure.

## Separate query and passage embedders

Recall queries and stored text can now use different embedding settings. Any `HINDSIGHT_API_QUERY_EMBEDDINGS_<X>` or `HINDSIGHT_API_PASSAGE_EMBEDDINGS_<X>` variable replaces `HINDSIGHT_API_EMBEDDINGS_<X>` for that side only — for example a fast local model for searches and a remote one for stored text.

## Custom LLM providers

For a backend no built-in provider speaks, set the provider to your own class by import path: `HINDSIGHT_API_LLM_PROVIDER=mypackage.llm:MyLLM`. It works in the global and per-operation settings and in a failover chain. Your class can also opt into batch requests.

## Reranker fallback for decision-model recall

Set `HINDSIGHT_API_RECALL_DECISION_MODEL_FALLBACK=true` and a recall the decision model fails or refuses is ranked by your configured reranker instead of failing. It's off by default.

## Smaller additions

- **Document tags**: `PATCH` a document with `add_tags` / `remove_tags` to change only the tags you name, without sending the full set.
- **Rotated database credentials**: `HINDSIGHT_API_DATABASE_CONNECT_HOOK` points at your own connect function, so new pool connections pick up fresh credentials.
- **Extensions** can review extracted memories and consolidation writes before they're stored, and refuse a refreshed mental-model page.
- **Stats** count mental models whose automatic refresh is paused, and `total_links` now counts every entity link.
- **Control plane**: per-bank toggles for recall prune and dedup.
- **CLI**: a native Windows x64 binary ships with each release.

## Reliability and speed

- Temporary failures and LLM-slot waits no longer pause a mental model's automatic refresh.
- Two concurrent retains of the same content store each fact once; batch extraction rejects duplicate custom ids.
- A deleted bank's running jobs no longer recreate it; a recreated bank no longer shows the old bank's stats.
- Clone, transfer import and rename can no longer take over an existing alias; two restores racing into the same new bank refuse instead of merging.
- On shutdown the worker stops claiming work at once and drains within the grace period.
- Retain skips the LLM pass when the embeddings backend is known to be down.
- Temporal recall works with dateparser 1.5.0.
- Faster recall, consolidation, entity search, staleness checks and knowledge-base folder deletes on large banks.
